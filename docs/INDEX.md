# docs

One line per page, opening with its kind. The kinds, and the rules a page is
judged by, are dotclaude's document-kinds spec,
<https://github.com/kalaluthien/dotclaude/blob/main/spec/document-kinds.md>;
each page names its kind on `<body class>` and, in its last line, the pattern
it follows and the sources it was read from.

- [planes.html](planes.html) — view: the three planes and one machine's cache,
  what each holds, and how one reaches another.
- [sub-issue-lifecycle.html](sub-issue-lifecycle.html) — view: a sub-issue from
  filing to release, in the planner's, the worker's and GitHub's lanes; the
  roles are the lanes.
- [scripts.html](scripts.html) — view: which caller runs each script, git, the
  harness, CI or a flow, and on which event; the live list is
  `scripts/campaign-primitives.py`.
